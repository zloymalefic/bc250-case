# Dual 180-degree USB return interface v0.1

## Available sources

Two project references already implement the mechanism:

- NexGen PRO V2 `pro-v2-usb-cover-multi-material.3mf`, raw envelope
  12.65 × 70.35 × 27.93 mm;
- NexGen Redux `redux-optional-usb-cover.3mf`, raw envelope
  12.65 × 70.35 × 32.58 mm.

The selected seller describes 180-degree USB couplers for confined spaces,
claims USB transfer up to 10 Gbit/s and 3 A, and lists several A-D variants.
The unstructured dimension list contains values from 24 to 32 mm without a
reliable variant-to-axis mapping.

## Project envelope

Until the delivered parts can be checked, each coupler receives a conservative
32 × 30 × 29 mm equipment envelope plus 1.0 mm clearance per side. Two couplers
are arranged under one NexGen-style protective hood.

The fixed chassis interface is based on the 70.35 mm reference-cover length.
The coupler-contact insert remains a small replaceable part. If the delivered A
or D variant differs, only that insert changes; the hood, rear panel, and case
do not.

Seller speed/current values are treated as claims, not verified electrical
ratings. The seller's stated manual-measurement error is too ambiguous for a
final press fit, so the first insert remains a fit-check part.

# BC-250 browser 3D viewer

Русская инструкция по установке и совместной работе: [`SETUP.md`](SETUP.md).

Быстрый запуск из корня репозитория:

```sh
python3 tools/dev_visualization.py
```

Открыть: <http://localhost:8000/visualization/>

Сервер следит за интерфейсом и готовыми STL и автоматически обновляет открытую
страницу. CAD автоматически не пересобирается.
